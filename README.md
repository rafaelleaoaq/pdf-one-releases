# PDF One

Editor de PDF leve, rápido e local para Windows: visualizar, editar, organizar páginas, juntar,
converter, comprimir, reconhecer texto (OCR), exportar para Word e assinar digitalmente
(ICP-Brasil), tudo offline e em português.

## Baixar

**[Baixar a versão mais recente](https://github.com/rafaelleaoaq/pdf-one-releases/releases/latest)**
— abra a página e baixe `PDF-One-Instalador-<versão>.exe`.

O instalador instala o PDF One para todos os usuários do computador (pede permissão de
administrador) e pergunta se ele deve ser o programa padrão para PDF. Também adiciona ao menu do
botão direito do Windows as ações rápidas (mesclar, comprimir ou dividir, converter para PDF).
Requisitos: Windows 10 ou 11, 64 bits.

## Atualizações

Quem já tem o PDF One instalado (versão 1.0.10 ou mais nova) é avisado automaticamente quando há
versão nova (*Sobre › Verificar atualizações* para verificar na hora). O instalador baixado é
conferido (SHA-256) antes de ser aberto, e suas configurações são mantidas.
